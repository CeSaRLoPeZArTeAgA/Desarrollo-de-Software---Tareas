PROYECTO: USO DEL SISTEMA DE REGISTRO DE INCIDENCIAS CIUDADANAS

ACTORES PRINCIPALES 
--------------------
Ciudadano - Persona/usuario que registra una incidencia desde la interfaz web.
Operador municipal - Persona encargada de revisar, gestionar y actualizar el estado de las incidencias
Sistema	Plataforma que valida -  almacena y muestra la información de las incidencias

CASO DE USO
------------
[1] REGISTRO INCIDENCIA CIUDADANA
[2] CONSULTA DE INCIDENCIA REGISTRADA
[3] ACTUALIZAR EL ESTADO DE INCIDENCIAS
 

HISTORIAS DE USUARIO (HU)
-------------------
HU1 - Registro de incidencia, asi como el ciudadano quiere registrar una incidencia de la via publica,
      para que la municipalidad pueda conocer el problema y atenderlo.

HU2 - Adjuntar evidencia, asi como el ciudadano, quiero adjuntar una imagen, video o audio al reporte, para demostrar mejor la incidencia registrada.

HU3 - Seguimiento de incidencia, es asi como el ciudadano, quiero consultar el estado de las incidencias registradas, para saber si mi reporte ya fue atendido o sigue pendiente.

HU4 - Gestión municipal de incidencias, es asi como operador municipal,quiero revisar las incidencias registradas por los ciudadanos, para priorizar y gestionar su atención.
